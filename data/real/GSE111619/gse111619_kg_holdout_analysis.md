## 两个 50% 的计算

- 整体覆盖率：普通 RAG 为 `9/32=28.125%`，图谱增强 RAG 为 `25/32=78.125%`，差值为 `(25-9)/32=50%`。
- 平均每题覆盖率：5 题增加 100%，2 题增加 50%，5 题没变，差值总和为 6，再计算 `6/12=50%`。
- 两个 50% 来自同一批 24 条回答和同一套命中结果，不是两份独立证据。因此不再把它们并列成两项主结论。

## 统计边界

图谱增强模式的逐题事实覆盖优于普通模式 7 题、持平 5 题、劣于 0 题，双侧精确符号检验为 `p=0.015625`。但题目不是第三方独立命题，该结果不能按确认性实验解读。封闭集精确正确性方面，仅图谱模式答对 5 题，仅普通模式答对 0 题，McNemar 双侧精确检验为 `p=0.0625`，未达到 0.05 水平。

## 错误与限制

- H02 中图谱增强回答仍将第二个对照样本映射到错误的 SRA 号。
- H03 中图谱增强回答未获得四个样本的完整计数，错误判断最高值样本。
- H08 中图谱增强回答把第二个对照样本的总计数重复成第一个样本的数值。
- H10 中两种模式都没有完整返回 TopHat2 与 HTSeq 的版本。
- H11 的自动规则因“剂量”和“doxycycline”在回答中不相邻而产生一次保守漏判，两种模式均受影响。
- “事实覆盖”只检查预设词项是否出现，不会判断关联、否定、推理和引用是否正确。
- 当前证据只来自一个 GEO 项目，不能直接外推到其他实验类型。

## 当前允许的表述

在本项目内部设计的 12 题、32 个预设事实自动评测中，普通 RAG 命中 9 个预设事实，图谱增强 RAG 命中 25 个。这说明图谱上下文在该内部题集中补充了更多预设关系词项。该指标是文本匹配覆盖，不是答案准确率；在独立人工盲评和外部测试集完成前，不将其作为论文的最终效果证据。

## 内部评测后的错误修复

内部评测后，H02、H03、H08、H10 被作为开发回归题，不再计入新的独立测试成绩。系统增加了处理组聚焦、关系均衡选择、字段用途标记和程序化数值比较。

- run #5：H02、H08、H10 全部严格答对，H03 仍失败。
- run #6：H03 的普通 RAG 事实覆盖率为 0%，图谱增强 RAG 为 100%，严格评分通过。
- 四个已知错误问题现已分别通过修复回归；结果保存在 `gse111619_kg_fix_regression_report.json` 和 `gse111619_kg_numeric_regression_report.json`。

这些回归结果只能证明已知错误被修复，不能替代新的独立测试。
