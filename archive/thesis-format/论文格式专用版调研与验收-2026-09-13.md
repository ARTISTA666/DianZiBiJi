# 安师大物电硕士论文格式：规范、选型与 specialized v1

本轮交付是面向本仓增强版论文的可复现 PDF 工具与123页排版预览。不是学院认证模板，也不是内容终审通过。论文源稿未修改；读取期间证据线仍持有论文写者窗口，本轮独立保存快照与素材，不占用该窗口。

## 1. 官方依据与适用范围

核验日期：2026-09-13。学院公开的[电子信息类专业学位培养方案（2021级及以后）](https://physics.ahnu.edu.cn/info/1168/6482.htm)第十节明确要求遵循学校硕士学位论文格式规定。因此本版以[研究生院《安徽师范大学关于硕士学位论文格式的规定（202003更新）》](https://gs.ahnu.edu.cn/info/1024/1683.htm)为基线；未找到可验证的、对本作者所属年级另行覆盖上述要求的物电学院排版细则。不能把其他学院规定、安徽大学 AHU 模板或本科论文格式套用在这里。

官网正文落款2015年、标题标202003更新，附件名称为“示图（硕士学位论文样式）2025.doc”，三者不是同一版本日期。附件下载进入验证码页面，本轮未取得其文件内容，因此不能宣称已逐像素复刻2025官方封面。学院页面的当前页头名称为“物理与光电学院”，正文保留此前培养方案；封面专业应以作者实际培养方案为准，工具不擅改学院或专业名。

| 项目 | 已核实的学校正文要求 | 专用版处理 |
| --- | --- | --- |
| 纸张、边距 | A4，四边2.8cm | 实际PDF全页A4；正文左界实测28mm |
| 正文 | 小四宋体，固定20磅 | 12bp/20bp；字体替代明确报告 |
| 章、节标题 | 小二宋体加粗；四号黑体 | 18bp、14bp；三级12bp是本版约定 |
| 图表题、表格 | 五号加粗；表格固定15磅 | 10.5bp加粗，表格内实测15pt基线；表上题/图下题为本版约定 |
| 页码 | 页面底部中央 | 已实现；前置罗马、正文阿拉伯为本版约定 |
| 封面 | 统一封面、中英文题名；专业按培养方案，分类号由图书馆核定 | 元数据集中；精确样式待附件核验，不猜填分类号和日期 |
| 摘要、关键词 | 中文一般1000字以内；中英文对应；关键词3–5个 | 提取原稿关键词；摘要1253个汉字，报告超限，不自动删改 |
| 装订 | 标题/签名、中英摘要、目录、正文、致谢、符号/图/表清单、文献、附录 | 主序已实现；清单尚未生成，签名为明确标注的预览页 |
| 打印 | 封面及前置材料单面；正文双面 | 由打印环节设置，本PDF不自动补背页 |
| 额外材料 | B5单面1500–3000字详细摘要 | 独立答辩材料，不混入正文，本轮未编写 |

来源文本没有明确规定“所有作者必须全部展开”“必须双语题注”“图片必须300dpi”“必须三线表”“正文西文必须TNR”；这些不能从旧 checklist 的勾选反推为校规。本版沿用三线表、TNR、两字符缩进等排版约定，区分于已核实硬要求。文献正文规定了基本著录字段，并没有直接指定 GB/T 7714 的某一版本。

## 2. 成熟项目调研与选型

| 项目与一手资料 | 可复用能力 | 本次决定 |
| --- | --- | --- |
| [Pandoc 手册](https://pandoc.org/MANUAL.html) / [许可](https://github.com/jgm/pandoc/blob/main/COPYING.md) | Markdown、LaTeX、DOCX转换；reference-doc继承Word样式，不复制模板正文 | 作为解析转换底座，不自行重写Markdown解析器 |
| [ChineseResearchLaTeX / bensz-thesis](https://github.com/huangwb8/ChineseResearchLaTeX/tree/main/packages/bensz-thesis) / [AHNU项目](https://github.com/huangwb8/ChineseResearchLaTeX/tree/main/projects/thesis-ahnu-master) / [MIT许可](https://github.com/huangwb8/ChineseResearchLaTeX/blob/main/license.txt) | 已有AHNU profile；覆盖中文学位论文；同校模板来源为公开样例和手册 | 复用本地已修补样式，缩减为单校样式文件；保留版权许可、固定实际文件哈希，不宣称官方认证 |
| [ThuThesis](https://ctan.org/pkg/thuthesis?lang=en) | 清华学位模板，LPPL许可，CTAN/TeX Live发行 | 借鉴结构，直接迁移清华排版成本高且不适配安师大 |
| [python-docx](https://github.com/python-openxml/python-docx) + Pandoc reference-doc | 可编辑OOXML、段落/分节样式 | 适合后续Word路线；当前大量TikZ和复杂表格不能直接保证保真 |
| [biblatex-gb7714-2015](https://github.com/hushidong/biblatex-gb7714-2015) | 中文文献著录样式 | 现有工程已用，但旧bib与当前源稿一致性尚不能直接假设；本轮保留原文编号，避免格式步骤覆写引用内容 |

推荐组合：**Pandoc → 单校CTeX/XeLaTeX样式 → latexmk收敛构建 → PDF检查**。不引入LLM自动改正文，不搭新Web服务。DOCX另开保真路线；上游也将DOCX定位为初稿，存在TikZ/复杂结构退化，不能把扩展名转换成功当成正式交付。

## 3. 旧流程实际缺陷与本轮修复

检查对象是本轮开始时的代码/本地工程，不以历史报告自称“已通过”为证据。

1. 历史shell入口硬编码绝对路径，旧页边距不符，吞掉编译错误后仍可复制PDF。本版按仓库定位输入，每次独立构建，外部命令失败即非零退出。
2. `/tmp/crlt/.../main.tex` 当时两次包含附录，遗漏致谢和签名页。现在从章节清单生成main，附录一次，恢复致谢并加清晰标识的签名预览页。
3. 转换器仍绑定旧日期、关键词和个人路径，非白名单图片会变占位框。现在元数据JSON集中管理，关键词取原稿，缺图报错。
4. 样式题注未落实五号加粗。现在显式10.5bp加粗；修复needspace与longtable共同导致的同页重复表头。续页保留正常表头。
5. 代码标识符、斜杠串和图形造成越界。添加不可见断行点、图形等比例限宽、图与题注同页，最终构建0条overfull警告。
6. 旧勾选表把部分本地约定写成硬要求。本报告重新区分来源已证实、工程约定和待核实项目；历史证据文件保持原样。

## 5. 验收边界

**工具v1已交付，论文格式终审待验。** 已知未完成项：2025官方附件精确封面核验、正式签名页、个人信息及日期、字体SimSun/SimHei终排、摘要压缩、符号/图/表清单与B5详细摘要（按学院最终提交清单落实）。当前环境使用Songti SC、Heiti SC替代，不冒称中易宋体/黑体。

此版本采用本论文表题映射和特定列宽修正；表号、章号继续变化时需要检查映射。它是针对现稿的specialized version，不能承诺修复任意DOCX或任意Markdown。`--strict`目前明确拒绝将预览模式当成提交终稿；启用正式模式需补齐已验证的官方页面。
