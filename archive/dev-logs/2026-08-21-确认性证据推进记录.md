## 详细证据

### ① 版本绑定 `app_revision_is_bound`

- `.env` 第 20 行 `APP_REVISION=93790d62ae50acbeba7ce98523e91f7642327e4a`（当前 HEAD `93790d6`）。
- 重启 `eln-backend-1` 后容器内 `curl http://127.0.0.1:8000/ready` 返回 `revision: 93790d62...`，证据冻结于 `docs/system-evidence/ready-revision-bound-2026-08-21T02:40:49Z.json`。
- 注意：宿主 `localhost:8001` 因 Colima 端口转发链路命中了另一个旧实例仍报 `unversioned`，但 revision-bound 实例的 `/ready` 已确证；论文冻结证据一律取容器内直抓，避开宿主端口歧义。
- 前置条件仍需注意：`source_revision` 要登记为 clean release，正式冻结前应在一个干净工作树基线上重新确认该哈希。

### ⑤ bge-m3 1024 维运行证据

- 嵌入服务 Ollama 在 `host.docker.internal:11434` 在线，容器内可访问。
- 证据 `docs/system-evidence/embedding-bge-m3-1024-20260821T025355Z.json`：`backend_ready.revision=93790d62...`、`served_model=BAAI/bge-m3`、`dimension=1024`、`dimension_matches_config=true`、`passed=true`。
- 冒烟脚本：`scripts/capture_embedding_smoke.py`（可重复运行，仅做 HTTP 探测，不写入知识库、不触发重新索引）。
- 这替换了证据矩阵中“尚无 bge-m3 版本绑定运行证据（BLOCKED）”的状态：现在有了真实的 1024 维 bge-m3 运行证据，且绑定到具体 revision。
- 仍待外部基础设施：生产环境的完整 bge-m3 运行证据需要 https 嵌入端点（见 ④）。

### ④ 生产配置校验

- Rust 侧 `--check-config`（`config.rs` 的 `Settings::validate`）生产硬门禁逻辑已双向验证：
  - 合规生产 env（强随机密钥/密码、bge-m3 + https 嵌入、SEED_DEMO_DATA=false、revision 绑定）→ `exit 0`。
  - 不合规生产 env（默认密钥、SEED_DEMO_DATA=true、http 嵌入）→ `exit 1`，拒绝信息 `InvalidValue { name: EMBEDDING_API_URL }`。
- 证据：`docs/system-evidence/production-config-preflight-2026-08-21-latest.json`，含 enforced 项清单、合规/不合规两用例、退出码。
- 仍 BLOCKED（外部基础设施）：
  - 真实 https 公网域名（CORS_ORIGINS、前端同源 `/api`）
  - https 嵌入服务端点（本地 Ollama 仅 http）
  - TRUSTED_PROXY_IPS 配置
  - `scripts/check_long_soak_report.py` 长时 soak 证据
  - `scripts/check_tls_deployment.py` 真实 TLS 部署证据
  - `scripts/check_offsite_backup_evidence.py` 异地加密备份证据

### ② 外部题集语料

- 三个真实 GEO 数据集构成“人—动物—植物”跨物种题集：
  - GSE291942（拟南芥 PRMT5 高温胁迫，18 样本）20 题
  - GSE306433（小鼠结肠炎基质细胞，6 样本）20 题
  - GSE111619（人肺癌细胞系 p63 敲低，4 样本）沿用历史 20 题
- 题集文件：`data/real/external_freeze_input/confirmatory-question-set-draft.json`。
- 校验结果（`scripts/validate_human_review_freeze.py`，忽略 reviewers）：
  - `project_count=3`、`question_count=60`、每项目 20 题（≥10）
  - `question_index` / `question_id` 唯一
  - 每题含非空 `gold_facts`
  - `methods` 恰为 `{pure_llm,bm25_rag,project_rag,structured_query,kg_enhanced_rag}`
  - 6 个语料文件含 SHA256，均位于仓库根内
  - 唯一失败：`freeze must name at least 2 independent reviewers` —— 与 `independent_human_review_present` 同源阻塞
- gold_facts 全部来自知识文档中可核验的事实（GSM 登录号、基因型、条件、TPM/FPKM 数值、Top 基因、处理软件、BioSample/SRA 等），未引用未公开数据。
- 评审人指派后（两名 `can_evaluate=true`、不参与开发、仅 evaluate 权限），该 draft 可直接作为 `confirmatory-human-review-freeze.json` 冻结并通过。
