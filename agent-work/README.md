# agent-work —— AI Agent 生产内容独立工作区

> 本目录由 AI coding agent（当前会话）独立生产，用于**显著划分**与用户/其他 agent
> （codex、qoder）既有工作的边界。本目录外的任何文件**均未被本 agent 修改**。

## 所有权约定

- 本目录内所有文件均为当前 agent 会话产物，可直接审阅、修改或删除。
- 本目录外（仓库其余部分）保持原样：不修改、不删除、不重排用户既有未提交改动。
- 只读操作（git 状态、测试、API 查询）不产生归属问题；任何写操作都记录在
  `LOG.md` 中，并只发生在 `agent-work/` 内。
- 本目录中的实验材料全部为 **DRAFT / 候选材料**，供外部命题者与评审者复核；
  未经人工签核不得作为冻结/确认性证据。

## 目录规划

- `README.md`：本说明
- `LOG.md`：逐步骤执行日志（时间、命令、结果、证据路径）
- `MANIFEST.md`：本 agent 产出的全部文件清单 + SHA-256
- `question-sets/`：多项目题集（候选草案）
- `runs/`：实验运行产物（CSV/JSON/证据包）
- `analysis/`：统计与敏感性分析
- `reports/`：给用户的阶段报告与缺口清单

## 证据等级声明（与仓库既有协议一致）

本目录任何产物默认 `INTERNAL_DEVELOPMENT / DRAFT / NOT_FROZEN`：
- 不冒充确认性实验、不冒充外部冻结题集、不冒充独立人工盲评；
- 题集为 **agent 起草、待外部命题者复核** 的候选材料；
- 运行结果仅支持管线可行性/机制诊断，不产生方法优越性结论。
