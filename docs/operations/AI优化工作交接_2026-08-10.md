## 最近完成的 AI 改动

### 1. 无资料库模式契约统一

- 纯 LLM 无需初始化项目资料库。
- 结构化查询只依赖知识图谱，也无需初始化项目资料库。
- 前端输入框、按钮和引导文案已与 Rust 后端 `mode_requires_dataset` 契约一致。
- E2E 同时覆盖纯 LLM 和结构化查询在空资料库状态下可提交问题。

主要文件：

- `frontend/src/app/(dashboard)/projects/[id]/ai/page.tsx`
- `frontend/e2e/system.spec.ts`
- `backend/src/api/rag.rs`

### 2. Agent 证据边界与溯源一致性

- Agent 只把 `knowledge_sync_status = synced` 且确有 RAG 正文的文件作为 `[F]` 证据。
- 待入库、失败或空正文文件只显示不可用状态，不生成 `[F]` 引用编号。
- 上下文截断后，引用审查和 `source_*_ids_json` 只记录模型实际看见的编号，避免“落库显示引用过、模型实际没看到”。
- `evidence_available` 由预算截断后的可见证据决定。
- 文件预览限制为每份 600 字，总上下文限制仍为 18,000 字。
- Agent 提示版本为 `agent-v9-budgeted-rag-evidence`，Python prompt registry 仅同步版本契约。

主要文件：

- `backend/src/api/agents.rs`
- `backend/app/services/prompts.py`

### 3. Agent 文件选择质量

- 数据库最多加载 48 份候选资料，优先已入库资料和较新资料。
- 每份文档读取前 4、后 4 个分块，避免永远只看文档开头。
- 根据任务关键词以及已审核笔记标题/实验类型进行相关性评分，再截取最多 12 份资料。
- 新增长文件预算、可见来源、相关性排序、未入库文件边界测试。

### 4. AI 结果可解释性

- AI 页面已暴露结构化查询模式。
- 回答元信息区分：纯 LLM 无项目证据、结构化查询未命中图谱证据、RAG 未命中项目证据。
- 资料引用和图谱引用继续保留可视化标记与跳转。

主要文件：

- `frontend/src/lib/citations.tsx`
- `frontend/src/app/(dashboard)/projects/[id]/ai/page.tsx`
