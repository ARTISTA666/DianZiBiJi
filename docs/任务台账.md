# 任务台账（task ledger）——所有 Agent 工作的登记处

> 目的：项目由多个 AI Agent 并行推进，作者不直接参与每次执行。**本台账是复盘的唯一入口**：谁、何时、做了什么、证据在哪、验收没有。
> 规则（2026-09-08 起）：
> 1. **开工先登记**：任何 agent 开始一个工作包前，先在"进行中"表加一行（ID、执行方、任务、范围）；大任务拆成多行。
> 2. **收工必更新**：完成后补"关键产出/提交"与"证据/报告"两列，状态改 `已完成`；**没有证据链接的完成不算完成**。
> 3. **验收分离**：跨 Agent 的产物（如 coordination 轮次报告）完成 ≠ 验收通过，验收方在"验收"列标注（`待验收`/`Codex 已验收 <日期>`/`作者已确认`）。
> 4. **一行一工作包**：轮次内的多步执行合并一行，明细留在各自报告（reviews/round-*、coordination/*、experiments/*），台账只放指针。
> 5. ID 递增（T-001…），永不复用；已收官的计划文档在"状态"列标 `已实现`/`已取代` 并注明替代物。
