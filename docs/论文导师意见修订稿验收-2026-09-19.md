## 必须修复的问题

### 1．直接引文被改写，且图谱引用有错配（优先）

位置：5.1 节 qPCR 资料示例、5.4 节图谱概览（PDF 第 53 页）。

Antigravity 将 qPCR 原始材料中的编号步骤合并成“实验流程包含……四个步骤”，却保留“全文为例”及引号。这是转述，不能继续冒充文件原文。`docs/experiments/rag-experiment-4.csv` 的资料片段保存了原始四步文本。

图谱概览也被改为“例如针对 PCR 条件优化实验，系统展示管理员创建关系……”，与 `docs/experiments/agent-graph_overview-final.json` 的实际生成正文不一致。去除作者行文中的机械编号不能延伸到改写原始实验输出。

此外，该处把 Taq DNA Polymerase 对应到 `[R1930]`；原始 JSON 明确为 `[R1929]`，而 `[R1930]` 是 dNTP。编号错配在本轮之前已存在，应一并修复。

修复要求：据原始工件恢复准确摘录；如采用概述，去掉“全文”“真实生成正文摘录”等直接引用承诺，并明确为作者概述；逐项对齐实体与来源编号。

### 2．将名义覆盖缺口改成了实验计划完成情况（优先）

位置：第三章功能需求，PDF 第 21 页。

现稿称预警指标为“计划未完成比例”。而 4.6.8 节定义的是有效计划知识点中未被同类型、同规范名实体匹配的比例。这只能反映记录与计划知识点之间的名义覆盖缺口，不能直接衡量实验任务是否完成。该措辞为本轮新增。

修复要求：使用“计划知识点未覆盖比例”等与公式、接口语义一致的名称，保留由人工判断实际进展的边界。

### 3．表格与正文的实验口径互相冲突（优先）

位置：表 6-1（PDF 第 62 页）和表 6-4、6.3/6.6.1 节。

表 6-1 将 legacy 批次适用范围写成“本文全部问答质量结论”，将 Rust 系统写成“仅证明系统可运行、模型可调用”；紧接着却报告 Rust 成对复现的事实覆盖率及 17/20、19/20 正确题数。应把历史实验 4/5、运行冒烟和独立 Rust 复现批次的适用范围分别说明。

表 6-4 称“每题预定义答案要点”，而正文明确为“事后制定”答案要点。预先制定与事后制定是不同评价设计，必须按实际工件统一，不得通过润色把事后规则写成预注册规则。

以上为原有问题，本轮保留了表格，因此没有修复。
