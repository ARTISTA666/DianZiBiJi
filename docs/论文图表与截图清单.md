- 不插入人工准确率、可追溯率或 1-5 分质量对比图，因为人工评价尚未执行。
- 不插入旧 Dify 配置失败截图；当前正式链路为本地 pgvector 检索与 DeepSeek 生成。
- 不建议插入过多系统管理截图，毕业论文重点应放在实验记录、知识图谱、RAG、智能体和审计追溯。
