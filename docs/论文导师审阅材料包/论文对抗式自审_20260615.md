# 论文对抗式自审

## 五维结论

| 维度 | 状态 | 依据 |
| --- | --- | --- |
| 贡献 | 需新实验 | 可回放证据链和失败机制分析成立,但尚不足以证明新的图检索方法贡献 |
| 写作清晰度 | 通过 | 研究问题、方法能力、失败原因和贡献边界已统一 |
| 实验强度 | 需新实验 | 单项目、20 题、单次生成,缺少重复与外部测试 |
| 评价完整性 | 需新实验 | 人工盲评、强基线、预注册规则和多项目留出测试未完成 |
| 方法合理性 | 需修订与实验 | 一跳排序适合直接关系题,但集合查询、指代和连接聚合需要新增查询算子 |

## 主要主张与证据

Claim:系统能够回放一次问答使用的业务状态、资料块、关系和模型配置。  
Evidence:问答日志保存项目、语料哈希、提示版本、资料块、关系编号、Token 和时延;权限与日志测试通过。  
Status:supported

Claim:当前批次中,图谱关系提高了事实型任务的答案要点证据覆盖。  
Evidence:18 个事实型任务的合并证据覆盖由 3/18 增至 12/18。  
Status:supported within the current batch

Claim:当前任务完成差异主要由检索证据覆盖解释。  
Evidence:两种模式在 18 个事实型任务上的证据覆盖数与最终完成数分别同为 3 和 12。  
Status:supported as an observational mechanism, not a general causal conclusion

Claim:固定 top-k 一跳检索不能稳定处理全量列举、跨问题指代和多关系聚合。  
Evidence:Q15 受 top-10 上限约束,Q17 缺少前序上下文,Q18-Q19 无法连接并聚合关系。  
Status:supported by failure cases

Claim:方法优于现有图增强 RAG 或适用于真实课题组。  
Evidence:缺少强基线、跨项目测试、重复运行和真实用户研究。  
Status:needs evidence and is not claimed in the revised thesis

## 提交前硬门槛

1. 独立评价者完成盲评签核。
2. 按预注册方案冻结答案规则后重跑实验。
3. 加入纯 LLM、BM25、直接结构化查询等基线。
4. 使用多项目留出测试并重复生成。
5. 对查询分解、结构化过滤、关系配额和连接聚合分别做消融。
