3. 对独立 Word/PDF，沿用来源文件、任务编号、完整路径与 SHA-256 建立版本链。完成不代表作者验收。
4. 已被替代的文档保留原文并标 `superseded`、补 `superseded-by`；历史实验结果与冻结证据不改写。
