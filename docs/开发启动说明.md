# 开发启动说明

## 默认技术栈

- 前端：Next.js + TypeScript + Tailwind CSS
- 后端：Rust + Axum（对外运行时）+ FastAPI/SQLAlchemy（容器内兼容服务）
- 数据库：PostgreSQL
- 部署：Docker Compose

## 首次启动

macOS 或 Linux：

```bash
cd /path/to/full-system
cp .env.example .env
docker compose up -d --build
```

Windows PowerShell：

```powershell
Set-Location C:\path\to\full-system
Copy-Item .env.example .env
docker compose up -d --build
```

项目不依赖固定盘符或固定目录。Windows、Intel Mac 和 Apple 芯片 Mac 使用同一套 Compose 文件。

启动后访问：

- 前端：http://localhost:3000
- 后端文档：http://localhost:8001/docs
- 后端存活检查：http://localhost:8001/health
- 后端就绪检查：http://localhost:8001/ready

## 开发环境初始账号

```text
账号：admin
密码：admin123
```

该凭据来自 `.env.example`，只用于本地开发。生产环境必须设置 `APP_ENV=production`、`SEED_DEMO_DATA=false`，替换 `SECRET_KEY`、`POSTGRES_PASSWORD` 和 `BOOTSTRAP_ADMIN_PASSWORD`，并配置 `DEEPSEEK_API_KEY` 与 `APP_REVISION`；不满足时后端拒绝启动。

Compose 默认运行构建后的 Next.js 生产服务，不挂载源码。修改代码后重新执行 `docker compose up -d --build`。上传文件默认保存在宿主机 `./storage`，可通过 `SYSTEM_STORAGE_PATH` 调整。

## 备份与恢复

```bash
scripts/backup-system.sh
scripts/restore-system.sh backups/eln-YYYYMMDDTHHMMSSZ --confirm-replace
```

备份期间会短暂停止应用写入，数据库服务保持运行。恢复前会自动创建回滚包，详细说明见 `docs/operations/backup-restore.md`。
