## 三、正式执行记录表

正式执行时，每个问题需要分别调用普通 RAG 和图谱增强 RAG。每条记录至少填写下列字段。

| 字段 | 填写说明 |
| --- | --- |
| question_id | Q01 至 Q20 |
| rag_mode | `project_rag` 或 `kg_enhanced_rag` |
| query_log_id | 系统返回或日志表中的问答编号 |
| answer_summary | 回答摘要，不超过 100 字 |
| source_count | 系统记录的资料来源数量 |
| graph_hit_count | 系统记录的图谱命中数量 |
| response_ms | 系统记录的响应耗时 |
| is_accurate | 人工判断是否准确 |
| is_traceable | 人工判断是否可追溯 |
| score | 1 至 5 分 |
| evaluator_comment | 评价说明 |

## 四、评价口径

准确性：回答与已审核实验笔记、资料库文件和知识图谱关系一致，且没有明显编造内容，则记为准确。

可追溯性：回答能定位到资料来源、实验笔记或图谱关系之一，且依据与回答内容相关，则记为可追溯。

评分：

| 分数 | 含义 |
| ---: | --- |
| 5 | 回答准确，依据完整，可直接用于实验记录复盘 |
| 4 | 回答基本准确，依据较完整，但表述略有遗漏 |
| 3 | 回答部分准确，但依据不充分或存在轻微遗漏 |
| 2 | 回答有明显遗漏，依据不足 |
| 1 | 回答错误或无法追溯 |
