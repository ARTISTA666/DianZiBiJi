## 四、论文创新点机制层真实性对账

本组多用户操作与截图/录屏记录与学位论文正文内容完全契合：

1. **创新点一：审核门禁下的动态知识蓝图与图谱持续更新（5.1.8 节、7.9.1 节）**
   - 界面上清晰呈现“实心节点 = 已实证”与“虚线节点 = 待实证知识缺口”；
   - 当前项目显示实证覆盖率为 **7%（1/15 个计划知识点）**，对应进展偏差率为 **93.3%**；
   - 数据库记录留痕与论文 7.9.1 节一致：首次解析 13 节点/12 边，二次增量解析补充 2 节点/2 边，唯一索引零冲突。
2. **创新点二：图谱与证据约束的科研辅助工作流（5.2 节、5.4 节、7.9.1 节）**
   - **主动建议**：AI 导师助手根据未覆盖的 14 个待实证节点，结构化生成三阶段建议（血浆采集 → 外泌体分离鉴定 → miRNA 测序验证），审计日志明确留痕 `agent_next_step_suggestion`；
   - **预警闭环**：预警收件箱实时核算四维指标，准确触发进展偏差严重告警，导师陈薇确认留痕备注真实记录在系统与界面上；
   - **双重引用**：问答结果中 `[S]` 资料片段与 `[G]` 图谱一跳关系明确标注，并可追溯对账。
3. **创新点三：面向导师监督的图谱语义可视化反馈（5.1 节、6.5 节）**
   - 实证图谱展示 86 节点、95 关系，涵盖 8 大实体类别；
   - 实现了 17 类实体色板、节点度数缩放、专属连线流向以及 Ego-Network 一跳局部聚焦虚化背景，辅助导师直观核查证据链。
4. **系统工程闭环与权限隔离（4.3 节、5.3.3 节）**
   - 四类角色（导师、审核人、普通成员、只读成员）在界面操作流与可用功能上呈现严密的权限隔离，与式(4-1)权限判定函数完全对齐；
   - 全局审计流水逐项记录了每个用户的登录、建议推导、审核与配置变更，落实“可信逐笔回放复核”承诺。
