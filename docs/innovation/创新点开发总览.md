## 二、四创新点如何互相咬合（答辩主线）

```
项目计划书/组会纪要 ──解析──▶ ①知识蓝图（计划态）
                                    │ 未覆盖知识点 = "下一步做什么"
                                    ├──────────▶ ②主动建议（AI 导师助手）
                                    │                    │ 学生执行
                                    ▼                    ▼
                              实验记录 ──审核门禁──▶ 实证图谱 ──覆盖──▶ ③可视化五通道
                                    │                                      ▲
                                    ▼                                      │
                              ④四维预警指标 ──越界──▶ 报警收件箱 ──导师确认/调阈──┘
```

- **蓝图定义预期，实证记录定义实际**：覆盖度同时驱动建议（②）、进展偏差预警（④）与可视化水波（③）；
- **每一步自定义规则都是答辩弹药**：蓝图来源优先级、覆盖判定口径、四维指标与阈值、
  视觉通道映射、建议生成协议——全部"现有产品做不到、必须自定义才能跑通"；
- **导师每个人工动作都留痕**：审批、确认报警、调阈值、作废蓝图节点，全部进审计日志，
  构成"人工反馈逐步收敛"的数据基础。

## 五、答辩第一问的标准答案链（导师面谈原文的落实；口径勘误 2026-09-07 ZC-02）

**"你怎么证明自己定的标准是对的？"**

1. 标准自定义合法：教学改革评价同理（对照班实验，标准是研究者定的，结论由数据支撑）；
2. 消融实验：输入属性有/无对比（批次 innov-ablation-01，`docs/experiments/innovation-ablation-2026-09-07.md`，
   **口径以该文件 2026-09-07 勘误版为准**）——蓝图有/无（建议引用绑定计数，非质量证明）、
   画像分数有/无（前瞻项 outlook，离线原型，无收益主张）、语义映射有/无（通道完备性；
   86:1 为成本模型推演值，**非效率证据**，人工识读实验待用户测试批次）；
3. 效率对比：`review_stall_hours` 指标**存在且可测**，但指标存在 ≠ 预警有效性实验证据；
   效果主张待有对照组的试用数据；
4. 用户证据：真实课题组试用 + 访谈/问卷进附录（待办，人工介入项）。
