# 创新点三 · 图谱可视化语义映射表 v1

> 来源：2026-09-06 创新点讨论（导师面谈录音）确立的创新点三——「知识图谱的多维可视化语义表达」。
> 本文是该创新的**机制定义文档**：视觉通道 ↔ 业务语义的映射关系、数据来源与设计边界。
> 实现代码：`frontend/src/components/kg-visualization.tsx`（v1 基线 tag：`innov3-vis-v1`）。

## 一、为什么这是一个创新点

主流知识图谱可视化（含开源 GraphRAG 工具、Neo4j Bloom 默认视图）的节点表达只有
「一个球 + 一条连线」：颜色多为随机分配，大小仅表示连接数，语义密度极低。
本系统针对科研实验记录场景，把图谱的**每个视觉通道都绑定一个业务语义**，
使导师在审核时可以**一屏读取项目状态**——可视化是给人看的，不是给机器看的；
它的价值是让人类审核者对 AI 结论做快速验证。

## 二、通道映射表（v1 已实现）

| 视觉通道 | 业务语义 | 数据来源 | 取值规则 |
| --- | --- | --- | --- |
| 颜色 | 实体类型 | `kg_entities.entity_type` | 18 类固定色映射（样本红、试剂琥珀、结果粉、笔记靛…） |
| 形状 | 实体角色 | `entity_type` 归组 | 圆=研究对象（样本/细胞系/Geo 登录号）；方=记录与组织（项目/笔记/附件/用户）；菱=材料与工具（试剂/仪器/软件）；六边=方法与过程（实验类型/处理/扰动/培养/分组）；三角=产出（结果） |
| 大小 | 关联度 | 入边+出边数 | `val = clamp(度数×2, 3, 12)`，连接越多节点越大（信息枢纽一目了然） |
| 水波填充高度 | 证据新鲜度 | `kg_entities.updated_at` | 全图归一化：最新更新=满波，最旧=0.15 底波；低波节点提示"该知识久未佐证、需复核" |
| 边颜色 | 关系语义组 | `kg_relations.relation_type` | 蓝=结构关系（含笔记/含附件/创建者/实验类型）；琥珀=使用关系（使用试剂/仪器/样本）；绿=产出关系（产生结果） |
| 边粗细+高亮 | 审核焦点 | 前端选中态 | 选中节点的一跳关联加粗高亮，其余淡出 |

## 三、预留通道（v2 演进，绑定后续创新点）

| 视觉通道 | 目标语义 | 依赖 | 说明 |
| --- | --- | --- | --- |
| 水波高度（切换） | **计划完成度** | 创新点一：动态蓝图 | 蓝图落地后，"计划节点"有预期工作量，波高=已核准记录覆盖/计划值。v1 由证据新鲜度占位，切换是语义升级而非推翻 |
| 边远近 | 关系强度 | 创新点一：蓝图关系权重 | 当前规则抽取置信度均质（0.7），距离通道暂不启用；蓝图关系携带强度后启用 |
| 节点透明度 | 证据置信度 | 消融实验产出 | 规则抽取置信度均质，LLM 抽取混合上线后启用 |
| 节点光环 | 学生画像/预警状态 | 创新点四：预警闭环 | 触发预警的实体加警示环 |

## 四、关键设计决策（答辩应对）

1. **"水波为什么现在表示新鲜度而不是完成度？"**
   视觉通道必须绑定**当前系统真实拥有的数据**，否则是造假。当前图谱只含"已做"
   （审核通过笔记的抽取结果），没有"计划"就没有完成度分母。v1 用真实数据
   （updated_at）承担该通道并明示语义；蓝图（创新点一）落地后通道切换为计划完成度。
   ——这本身就是"先想清楚再动手"的映射表纪律。

2. **"这些映射是谁定的？凭什么？"**
   映射由作者依据科研记录业务定义（导师面谈确认），判定标准是**导师审核效率**：
   颜色/形状回答"这是什么"，大小回答"什么是枢纽"，水波回答"什么需要复核"，
   边色回答"这笔实验用了什么、产出了什么"。与教学改革评价同理：标准自定义，
   结论由数据验证（见消融与用户测试计划）。

3. **与已有产品的差别**
   Neo4j Bloom / 开源 GraphRAG viewer 的默认视图无形状编码、颜色随机或单一类型着色、
   无进度语义通道。本映射的每个通道都对应一个审核者要读的问题，属于业务创新。

## 五、验证方式

- 功能验证：`npm run lint && npm run typecheck && npm run build`；真实项目图谱页人工核验。
- 效果验证（论文实验部分）：后续以"有无语义映射"两条件做用户识读对比（找节点/
  判断时效/发现枢纽三类任务的反应时与正确率），并入消融表；样本量不足时以
  课题组内试用 + 访谈记录补充（见创新点讨论待办清单第 7 条）。
