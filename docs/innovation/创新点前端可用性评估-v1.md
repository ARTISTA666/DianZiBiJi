# 创新点前端可用性评估 v1（给 Antigravity 的修改清单）

> 写者：ZCode（证据线）。日期：2026-09-08。评估对象：`cc4eb8a` 部署栈实测走查（Playwright 自动化 + 截图）。
> 用途：Codex 裁决后可整体转派 AG 线；本文件只记录现象与位置，**不预设实现方案**。
> 优先级口径：P1=影响演示/试用第一印象；P2=明显摩擦；P3=打磨。

## 一、实测发现（按优先级）

### P1-1 Agent 助手浮动层遮挡页面按钮，且浮层文字超长不可折叠
- **现象**：Agent 侧栏回答长文本后，底部浮出的消息气泡（`fixed bottom-5 right-5 z-[60]`）覆盖了"预警"页右上角的"调整阈值"按钮，Playwright 与人工点击均被遮挡；自动化与人工都需要先手动收起侧栏才能继续操作。
- **位置**：`frontend/src/components/shared/AgentAssistant.tsx`（悬浮通知气泡容器）+ 侧栏折叠逻辑。
- **建议**：①通知气泡自动限时消失或可一键收起；②侧栏展开时点击外部区域即收起；③长回答默认折叠（"展开全文"），当前整段铺开约 300+ 字。
- **影响**：演示时若 AI 回答很长，导师会看到"页面点不动"，观感扣分。

### P1-2 图谱悬停聚焦命中率低（需要精确压在节点上）
- **现象**：86 节点全景下，在节点视觉密集区多点移动鼠标（5 个采样点、每点 700–1500ms），多数采样点未触发聚焦效果；"释放固定""标签"等按钮倒是一直可见。悬停命中需要非常贴近节点圆心。
- **位置**：`frontend/src/components/kg-visualization.tsx`（射线拾取层 `nodePointerAreaPaint`，AG-01 已注明这是刻意实现）。
- **建议**：①扩大拾取半径（节点 10–18px，拾取区域建议 ≥24px）；②或默认开启"标签"让文字也可命中；③提供"点击锁定 + 释放固定"的明确提示文案。
- **影响**：演示时"悬停聚焦"这个主打交互容易演砸——导师随手一放可能毫无反应。

### P1-3 AI 问答"引用校验未通过"横幅文案自相矛盾
- **现象**：横幅文本为"引用校验未通过：引用校验通过，共核对 22 个证据编号。 缺少强制引用：……"——开头否定、后文肯定，普通用户无法判断这次回答到底有没有问题。
- **位置**：AI 问答引用校验横幅渲染逻辑（`frontend/src/app/(dashboard)/projects/[id]/ai/page.tsx` 一带）。
- **建议**：拆成两段状态——总体判定（通过/降级 needs_review）+ 明细（"22 个编号核对通过，1 处关键事实缺强制引用"），并把"引用校验通过，共核对 22 个证据编号"从失败前缀里挪走。
- **影响**：这是答辩演示的高频页面，文案自打架会显得系统不可信。

### P2-1 报告页存在 3 条历史"状态： 失败"记录长期置顶
- **现象**："运行记录"列表顶部 3 条失败记录（2026/9/1，DeepSeek thinking 模型 max_tokens 耗尽导致，已在 97ffd43 修复），排在成功记录之前，演示时第一眼看到的是"失败"。
- **建议**：①失败记录默认折叠/后置（成功记录优先）；②或加"仅看成功"过滤；③失败原因悬停提示（当前无任何原因说明）。
- **位置**：报告页运行记录列表（`frontend/src/app/(dashboard)/projects/[id]/reports/page.tsx` 一带）。

### P2-2 蓝图页与图谱页的能力重复入口混乱
- **现象**：图谱页内有两个二级标签（实证图谱/知识蓝图），但"下一步指引"缺口清单在蓝图页；AI 问答页顶部的建议卡也列同样的缺口。三处入口没有互相跳转链接（蓝图缺口 → AI 建议 / AI 建议知识点 → 图谱节点有跳，蓝图缺口 → AI 建议无直达）。
- **建议**：在蓝图缺口详情面板加"让 AI 围绕此缺口给建议"按钮，打通"缺口→建议→行动"闭环叙事。

### P2-3 蓝图页文案自相矛盾（历史残留）
- **现象**：蓝图页图例仍写 **"实心水波 = 已获实验记录实证""形状=实体角色 · 颜色=实体类型"**——水波通道与形状区分已在极简重构中删除（AG-02 口径），文案与实际视觉不符。
- **位置**：`frontend/src/components/kg-blueprint.tsx` 图例文案。
- **建议**：改为"实心节点=已实证 / 虚线节点=待实证""颜色=实体类型"，删除"水波""形状"表述。**这条同时是论文诚实口径风险**（机制文档 v1.1 已声明裁撤，界面却仍在宣传）。

### P3-1 "发送"按钮禁用态无解释
- Agent 输入框为空时发送按钮禁用，但无 tooltip；演示时无碍，打磨项。

### P3-2 顶部统计卡与筛选区在 86 节点全景下视觉层级偏挤
- 左侧筛选区（下拉×2 + 8 个类别按钮 + 开关 + 图例 + 导航带）信息密度高，建议折叠分组（"筛选"与"导航"两个折叠面板）。属 AG 线自由裁量。
