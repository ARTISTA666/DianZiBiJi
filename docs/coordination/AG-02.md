## 二、代码实际实现的视觉通道核查

经对 `frontend/src/components/kg-visualization.tsx` 静态代码的逐行审计，真实运行基线如下：

### 1. 几何形状（Circles Only）
- **实现形态**：全量纯圆几何点。
- **代码定位**：L150-173（`ENTITY_SHAPES` 中 22 种类型全部映射为 `"circle"`），L200-203（`traceShapePath` 统一执行 `ctx.arc(x, y, r, 0, Math.PI * 2)`），L582-586（`paintNode` 统一绘制纯圆）。
- **说明**：早期草案中的 5 类角色多边形编码已在极简重构中彻底移除，当前不存在方、菱、六边或三角形。

### 2. 颜色与类型计数核实（18 vs 17 裁定）
- **显式类型数量**：**17 类**。
- **代码定位**：L103-121（`ENTITY_COLORS` 字典显式定义 17 个键值）：
  - 实验笔记 `note: "#6366f1"`
  - 课题 `project: "#3b82f6"`
  - 试剂 `reagent: "#f97316"`
  - 化学品 `chemical: "#f59e0b"`
  - 仪器 `instrument: "#64748b"`
  - 软件 `software: "#475569"`
  - 产物/结果 `result: "#0ea5e9"`
  - 生物样本 `biosample: "#14b8a6"`
  - 基因/靶标 `gene: "#10b981"`
  - 蛋白 `protein: "#059669"`
  - 疾病 `disease: "#ef4444"`
  - 细胞系 `cell_line: "#ec4899"`
  - 处理条件 `treatment: "#eab308"`
  - 培养条件 `culture: "#84cc16"`
  - 扰动 `perturbation: "#f43f5e"`
  - 人员 `user: "#8b5cf6"`
  - 文件 `file: "#06b6d4"`
- **回退兜底规则**：L192-194（`getEntityColor(type)` 对未匹配类型统一返回板岩灰 `#64748b`）。
- **18 vs 17 差异成因与感知辨识局限**：旧文档草案将实体类型概括为“18 类”，实际上在当前前端基线中，`ENTITY_COLORS` 显式定义了 17 项，其余未匹配类型通过默认板岩灰 `#64748b` 兜底。必须明确客观局限：
  1. 17 个显式映射**不代表 17 种独立可辨颜色**（未经 CIELAB 感知独立性验证，相邻类别如基因 `#10b981` 与蛋白 `#059669` 同属绿色系、试剂 `#f97316` 与化学品 `#f59e0b` 同属橙色系，视觉辨识度有限）；
  2. 默认兜底色 `#64748b` 与仪器类型颜色完全相同；
  3. 坚决避免使用“17+1 类高对比色”等误导性表述，客观规范为“17 类显式类型映射 + 1 类通用兜底映射”。
- **连线颜色**：L124-148（`RELATION_COLORS` 显式定义 22 类关系颜色，其余回退 `#94a3b8`）。

### 3. 大小通道公式（Size Formula）
- **代码定位**：L273-276。
- **计算逻辑**：
  - 实验笔记与课题枢纽节点：固定为 18px；
  - 普通实体节点：执行平滑开方缩放：
    $$\text{radius} = \text{clamp}(9.5, 13.5, 9 + 0.9\sqrt{\text{degree}})$$
- **说明**：取代了旧文档中粗糙的线性公式 `clamp(度数×2, 3, 12)`，防止高度连接的枢纽节点无界放大破坏布局。

### 4. 连线与关系（Edges）
- **代码定位**：L646-679（`paintLinkCanvas`）、L907-926（箭头与曲率配置）。
- **形态**：关系语义颜色着色，带流向箭头（相对位置 0.88，基础长度 3.5，聚焦态加长至 6.5），微小曲率 0.06 避免双向边重合。聚焦时在中点浮现深色半透明圆角药丸显示关系标签。

### 5. 聚焦机制（Focus & Ego-Network）
- **代码定位**：L548-580（光晕与聚焦判定）、L680-692（70ms 移出防抖）、L1049-1050（`nodeVisibility` 与 `linkVisibility` 剔除）。
- **形态**：鼠标悬停或选中节点时，全图仅保留该节点及其一跳（1-hop）相邻节点与连线，其余所有非相关节点与连线完全隐去。
- **光晕环规则**：
  - 焦点中心：双层光晕环（半径 $r + 5.5/\text{scale}$ 半透明外晕 + 半径 $r + 2.5/\text{scale}$ 描边）；
  - 1-hop 相邻节点：单层高亮轮廓（半径 $r + 2/\text{scale}$）；
  - 70ms 防抖缓冲：指针划过节点边缘间隙时不闪现全图。

### 6. 证据时效性（Drawer Freshness）与水波清除声明
- **水波已彻底清除**：早期在 10~18px 微型节点内绘制正弦波液体的尝试已彻底删除，Canvas 上没有任何水波/波浪渲染。
- **严禁概念混淆**：**现存的光晕环（Halo）为焦点交互层级指示器，绝对不是水波通道的重命名或演进形态**。
- **真实新鲜度位置与概念界定**：L269-270 计算全图更新时间跨度归一化值 `freshness ∈ [0.15, 1.0]`，并在 L1127 仅于右侧检视抽屉中以精确百分比文本显示（`{(freshness * 100).toFixed(0)}%`）。**重要概念明确：新鲜度纯粹是基于 updated_at 的相对时间派生值，不是证据正确性、置信度或研究完成度**（尽管检视抽屉 UI L1125 处标签误显示为“置信度”，学术界定与机制文档中必须严格区分）。

   - 坚决杜绝在未经严格性能基准测试前断言“消除了卡顿和震颤”。
2. **客观工程与交互意图表述规范**：
   - **渲染工程实现与设计意图**：Canvas 显式配置 `autoPauseRedraw={false}`（维持常驻动画重绘循环）并配置独立的 `nodePointerAreaPaint` 射线拾取层（Shadow Canvas）。其**设计意图**是在物理引擎停止后维持连续动画重绘并避免拾取层与视觉层绘制冲突，**实际帧率表现与交互平滑度明确待受控基准测试验证**；
   - **认知降噪意图**：通过实体语义色彩、度数平滑缩放与鼠标悬停触发的 Ego-Network 一跳网络局部聚焦，其**设计意图**是在导师审核时减少全局噪点干扰并突出局部证据拓扑关系，**实际对导师审核认知负荷的改善程度与识读耗时明确待受控人工实验检验**；
   - **概念界定边界**：17 类显式类型映射不代表 17 种独立可辨颜色，默认色与仪器同色；新鲜度纯为基于 `updated_at` 的时间派生值，非正确性、置信度或研究完成度；无原始文献来源严禁断言竞品缺失能力。

## 六、前端对后端接口依赖协作说明 (Frontend Notes for ZCode)

> **权属边界说明**：ZCode 专属拥有 `README/HANDOFF` 及总览/实验文档。前端 Agent 不在根目录或他人目录创建 HANDOFF 文件，仅在此处陈述前端后续联动所需的接口依赖：

1. **`KgEntity.updated_at`（时效性基准）**：
   - 需确保该字段在实体更新或抽取时写入真实有效 ISO-8601 时间戳，避免大面积均质同值影响归一化区分度。
2. **`KgRelation.confidence`（关系置信度）**：
   - 前端已支持在连线药丸与抽屉中格式化展示置信度浮点值，待混合抽取上线后由后端输出具有梯度区分度的数值。
3. **蓝图实证覆盖聚合（未来进度环依赖）**：
   - 若后续要在蓝图节点外围渲染完成度进度弧，需后端在蓝图接口中透传该计划节点的已核准实证覆盖率。
4. **实体异常与停滞警示标记（未来预警环依赖）**：
   - 若要实现预警闭环的节点脉冲光环，需后端在图谱实体数据中透传预警状态标记（如 `alert_level`）。
