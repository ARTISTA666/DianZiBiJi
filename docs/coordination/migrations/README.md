# 对话迁移总结归档

本目录专门保存因对话过长、上下文压缩次数过多或需要迁移到新对话而生成的项目总结文件。

## 命名与编码规则

文件名格式：

```text
NNN_YYYY-MM-DD_<内容类型>.md
```

- `NNN`：三位递增序号，按生成时间排序；不足三位补零。
- `YYYY-MM-DD`：总结生成日期，使用项目所在时区 Asia/Shanghai。
- `<内容类型>`：简短、稳定、使用小写英文和连字符，例如 `chat-handoff`。
- 同一天生成多个文件时，继续递增序号，不覆盖已有文件。

示例：

```text
001_2026-08-13_chat-handoff.md
002_2026-08-20_chat-handoff.md
```

## 归档要求

每份迁移总结至少包含：

1. 用户目标和工作约束；
2. 当前项目边界与工作区状态；
3. 已完成工作及对应验证；
4. 当前阻塞和明确的论文结论边界；
5. 关键文件索引；
6. 新对话启动后的下一步；
7. 生成时间、项目根目录和版本信息。

逐轮细节继续记录在项目根目录的 `NIGHT_LOG.md`；本目录文件是面向对话迁移的压缩交接材料，不替代源代码、原始实验数据或审计产物。
