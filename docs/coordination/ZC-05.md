2. **蓝图解析请求文本不落库**：`kg_blueprint_documents` 与审计均不存原文 → 同文本二次解析不可复现（①-A 降级直接原因），解析耗时也未记 duration_ms。补两处留痕是小改动，**列为待授权开发项**。
3. **建议正文（related_labels）不落库**：审计只存统计量 → ZC-03 ①-B 的 B4 补录设想不可行；migration 0017 的 `agent_suggestion_feedback` 表已建（含 Rust schema v6 runtime DDL），但**前端采纳/忽略按钮未接线**（= DS 行动卡 B2 / ZC-03 C2 的待授权开发项），现状是"后端先行、前端缺口"。
