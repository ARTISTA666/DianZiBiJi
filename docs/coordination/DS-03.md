## 3. B1 · 双时态（生效/作废时间戳）设计草案 —— 只设计，未动码

> 对齐结论（ZC-04 §2）：列为"待授权开发项，暂缓"。本节给出可裁决的最小改造点；**本节全部工程事实以 HEAD `209c75c` 源码为准，行号为当次读取值**。

### 3.1 现状锚点（读码所得）

- `backend/src/db.rs:587-623`：`kg_blueprint_nodes` / `kg_blueprint_edges` 均带 `status` 字段（默认 `planned`），且已存在**部分唯一索引** `uq_kg_blueprint_node_label (project_id, entity_type, normalized_label) WHERE status <> 'retired'`——"失效行退出唯一约束"的语义基础已经存在。
- `backend/src/kg_blueprint.rs:92-162` `upsert_blueprint_node`：冲突时（同项目+类型+规范名），新来源 priority 更小者**就地 UPDATE** 覆盖 description/source_kind/source_label/priority（L121-139）；被覆盖的旧值不留列，仅审计事件留痕——这就是"三周前的计划查不回来"的代码位置。
- `backend/src/db.rs:625-638`：`kg_blueprint_documents` 只存解析元数据（node_count/edge_count/message），**无 payload 快照**——历史留痕在审计表，不在可查询的一等对象里。
- `backend/src/kg_blueprint.rs:214` `parse_blueprint_document`、L522 证据行、L539 `project_blueprint`：覆盖度计算与查询视图未区分时间维度。

### 3.2 最小改造方案（A：列级双时态，推荐）

1. **迁移**（取下一个可用序号；0017 已被 ZC-05 采纳留痕占用，见台账 Q-12）：`kg_blueprint_nodes` / `kg_blueprint_edges` 各加 `valid_from timestamptz NOT NULL DEFAULT now()`、`invalid_from timestamptz NULL`、`superseded_by integer NULL`；两个部分唯一索引改为 `WHERE status <> 'retired' AND invalid_from IS NULL`。
2. **写入语义**：`upsert_*` 冲突分支从"就地 UPDATE"改为"旧行 `SET invalid_from = now(), superseded_by = 新id` + INSERT 新行"（旧值完整保留在旧行，天然可回查）；Added/Updated/Kept 三态计数语义不变。
3. **查询语义**：默认视图统一加 `AND invalid_from IS NULL`；新增 `as_of` 查询参数：`valid_from <= $ts AND (invalid_from IS NULL OR invalid_from > $ts)`；**覆盖度计算只数当前有效行**，防止双计。
4. **回滚锚点**：down 迁移删 3 列 2 索引即可整体回滚；存量行 `valid_from = created_at` 零破坏；建议里程碑 tag `innov1-bitemporal-v1`（挂 feature/innovation-demos，与既有 innov1~4 tag 体系一致）。
5. **前端**：非必需——后端能力先落；"按时间回看"游标为可选二期。
6. **审计**：审计事件格式不变（低成本）；`kg_blueprint_documents` 不动（它是解析事件账，不是状态账）。

### 3.3 工作量与风险

- **工作量**：1–2 天（迁移 + 双 upsert 改写 + as_of 参数 + 3 项集成测试），与行动卡 B1 估算一致。
- **风险**：① 部分唯一索引口径改错→并发双解析同秒插入重复行（缓解：事务内"先失效后插入"，与现有 initialize_database 死锁修复同一套锁纪律）；② 覆盖度/统计口径漏过滤失效行→双计（缓解：查询封装单点收口）；③ 演示口径：能力名称是"计划演化可回查"，**不能写"优于 Graphiti"**（S1 场景为企业对话记忆，DS-02 C2 红线继续适用）。
- **决策请求**：是否立项由 Codex 裁决；本线未动任何代码。

1. "以颜色承载实体类型的选择依据是图形感知的经典有效性层级（位置 > 面积 > 角度 > 体积）；该层级源自 Cleveland & McGill 的经典结论，近期研究进一步表明它是『平均观察者』结论、个体差异显著 [2212.10533 §1、§IV-A]。**不得把层级本身算作该文发现。**"
