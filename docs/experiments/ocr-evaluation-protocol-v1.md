# 图片 OCR 评价规则 v1

## 1. 目的

验证系统能否处理真实实验笔记图片，以及人工校对是否降低识别错误。该评价不用于证明 RAG 回答准确率。

## 2. 数据要求

每个样本必须同时保留：

- 原始图片或 PDF 页面；
- 与原图对应的独立人工转录；
- 系统第一次生成的原始 OCR 文本；
- 校对人员只看原图得到的修正文本；
- 来源地址、使用条件和各文件 SHA-256。

缺少独立人工转录时，只能展示 OCR 功能，不能计算错误率。

## 3. 当前候选数据

首选 Smithsonian 的 `Home Journal Invention Notebook, Volume 1`，项目编号 7578。该项目是真实的 19 世纪实验记录，页面包含手写文字、数值、图示和实验过程，并提供已经完成复核的转录。

候选页 `NMAH-AC0124-0000005-41` 记录了 1881 年 Bell 与 Charles Sumner Tainter 的录音圆盘实验。数据身份和当前下载状态见 `data/real/smithsonian_tainter/README.md`。

由于该站点拒绝了本地下载，当前还没有把它用于正式计算。

为先检查系统的失效处理边界，项目另使用 RUKOPYS 乌克兰语大学考试扫描件完成 10 页跨语种压力测试。该实验使用 `ukr`，而系统面向中英文资料的业务默认配置是 `chi_sim+eng`。该数据有专业人工转录，但在语种、文字系统和材料领域上均不匹配，因此只能检验复杂输入下是否强制人工确认，不能代替正式的中英文同领域评价。结果见 `ocr-rukopys-stress-test-2026-07-12.md`。

## 4. 样本选择

正式验证至少选择 10 个非空页面。样本选择在运行 OCR 前完成，并写入清单。不得因为某页识别效果差而替换样本。

若使用完整项目 PDF，按以下固定方法取样：

1. 按扫描顺序排列全部页面。
2. 删除标准转录中没有可见文字的空白页。
3. 从剩余页面中等间隔选取 10 页。
4. 冻结页码、来源地址和文件哈希。

## 5. 人员隔离

- 校对人员只查看原图和系统 OCR，不查看标准转录。
- 标准文本整理人员不查看系统 OCR。
- 文件冻结后再运行评价脚本。

同一人必须承担多项工作时，应按“先冻结标准文本，再运行 OCR，再校对”的顺序进行，并记录时间，避免根据 OCR 结果修改标准答案。

## 6. 计算方法

主要指标为字符错误率：

`CER = 编辑距离 / 标准文本字符数`

编辑距离是把 OCR 文本变成标准文本所需的插入、删除和替换次数。CER 越低越好。

系统同时报告：

- 原始 OCR 的 CER；
- 人工校正后的 CER；
- 删除空白字符后的 CER；
- 数字标记的精确率、召回率和 F1；
- 校正前后 CER 的百分点变化。

微平均 CER 使用全部样本的编辑距离总和除以标准字符总数。宏平均 CER 是各页面 CER 的简单平均。两者必须同时报告。

## 7. 执行方法

评价清单表头见 `ocr-evaluation-manifest-template.csv`。运行命令：

```bash
python scripts/evaluate_ocr.py \
  --manifest data/real/smithsonian_tainter/ocr_manifest.csv \
  --output data/real/smithsonian_tainter/ocr_evaluation_report.json
```

报告会保存输入文件的 SHA-256、每页编辑距离和汇总结果。任何百分比都可以从报告中的字符数和编辑距离重新计算。

## 8. 结果边界

截至 2026-07-13，RUKOPYS 开发集原图 Tesseract 的微平均 CER 为 75.72%；固定灰度 Otsu 方案在独立留出集上的微平均 CER 为 78.58%。未针对该数据微调的 HTRflow/TrOCR 基线在开发集和留出集上的微平均 CER 分别为 107.02% 和 111.51%。CER 可以超过 100%，因为插入、删除和替换总数可能超过标准文本字符数；它不是准确率。结果说明这些固定基线都不适合直接识别当前连续手写体。这些数字是外部手写压力测试结果，不是实验笔记准确率，也不是中文 OCR 结果。

真实实验笔记候选数据仍未成功下载，因此论文中不能写“系统已经准确识别真实实验笔记”。现有 RAG 指标截图只能证明截图文字可被提取，也不能作为实验笔记 OCR 准确率证据。
