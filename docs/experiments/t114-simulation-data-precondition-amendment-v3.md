# T114 模拟问答资料入库补测 v3

原角色验证保持 [补验协议v1](t114-supplement-validation-protocol-v1.md) 及 simulation/protocol-v2.json 的身份。项目2只建并批准三条笔记，没有导入普通RAG所需知识资料，原六次问答全部返回409，未到生成模型；原轮24场的这些失败不得回填为成功。

本修正于观察上述前置条件缺口后登记。管理员在同一独立模拟项目2导入与项目1相同的四份公开派生资料，完成审批与索引；不改项目1任何冻结内容，也不修改已批准的三条笔记。补测前冻结文件哈希、实际Rust资料状态、原完整动作日志、原六条问答与三条创建请求。

v3只另做三类任务各三次，共9场：样本条件问答、抗体参数资料不足问答、只读写入拒绝。九条请求字节复用原viewer请求，不按响应改问题或模式，问答仍用project_rag并实际调用生产Rust与DeepSeek。成功规则沿用原协议；全部计划调用均执行，失败照录，不增加问答尝试。GPT角色仍是会话内模拟，零真人；本轮不是独立确认性重复。

原24场结果与补充9场分别统计，不将二者合并成24/24或33场独立样本。新日志写simulation-v3/actions.jsonl，新GPT决策单独保存；原日志与角色决策只读保留。补测可核验资料入库后的功能与同一只读角色的权限，但不补造前端操作、MCP、真人体验或研究者金标准。
