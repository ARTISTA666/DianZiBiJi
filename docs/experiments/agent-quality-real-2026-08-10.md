# Agent 五任务真实模型验收（2026-08-10）

## 结论

当前安全配置下，DeepSeek 最小回归 3/3 通过；五类 Agent 冻结题集的首轮真实模型自动门槛通过。五任务合计使用 3,408 tokens，总响应时间 22,075 ms，单题最大 6,837 ms。提供方响应未返回费用，因此不在缺少当期价格快照时推算金额。

| 拒答/不过度推断边界 | 100% | 100% |

## 待复核信号

- 文献综述严格 citation precision 为 50%。模型使用了金标准没有映射到具体事实的额外来源编号；必须查看匿名回答正文后，人工判断它们是合理补充还是悬空引用。
- 异常检测的 Ct 31.7 规则未命中，单题事实一致性和 citation recall 均为 66.7%。由于脱敏归档不保存回答正文，目前不能区分模型漏报与“偏离”的同义表达导致的自动规则假阴性。
- `human_review_status` 保持 `pending`。本结果不能表述为科研用户验收通过。

## 证据边界

本轮直接使用与 Rust Agent 一致的系统提示契约和冻结合成上下文调用提供方，验证模型生成端；它没有经过 Rust API 的数据库取数、文件相关性排序、18,000 字截断和结果落库。全链路行为仍由 Rust 单元测试和系统 E2E 覆盖，真实数据全链路及人工盲评仍是上线前人工项。

脱敏机器报告见 `docs/experiments/agent-quality-real-2026-08-10.json`；冻结协议见 `docs/experiments/agent-quality-protocol-v1.md`。
