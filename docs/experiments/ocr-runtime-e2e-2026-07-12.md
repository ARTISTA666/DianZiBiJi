## 验收范围

本次验收只检查图片 OCR 的真实运行流程，不计算 OCR 准确率。输入图片是之前用于界面检查的 RAG 指标截图，不是真实实验笔记。图片中的 `28.12%`、`78.12%` 和 `+50.00 个百分点` 只是被识别文字，不能作为系统效果结论。

## 验收过程

1. 将图片作为知识文档上传并审核通过。
2. 在没有确认 OCR 结果时请求入库。
3. 系统返回 HTTP 502，原因是图片 OCR 必须先校对并确认。
4. 调用 OCR 接口，得到 332 个字符，状态为 `pending_review`。
5. 对照图片把“履盖率”修正为“覆盖率”，整理空白后确认并签名。
6. 再次请求入库，系统返回 HTTP 200，文件状态变为 `synced`。
7. 查询 RAG 分块，确认入库的是人工校正文。
8. 查询审计日志，确认上传、审核、失败入库、OCR 提取、OCR 确认和成功入库都有记录。

## 结论与边界

本次结果证明系统已经真实完成“图片上传、OCR 提取、人工校对、确认签名、未确认禁止入库、确认后使用校正文入库、审计留痕”的闭环。

本次结果不证明 OCR 对真实手写实验笔记的准确率。该结论仍需使用公开真实笔记图片和独立人工转录，按 `ocr-evaluation-protocol-v1.md` 计算字符错误率后才能得到。
