# RAG 实验 5 预注册方案

状态:待执行

冻结日期:执行前由研究者填写

## 1. 研究问题

- RQ1:在相同项目语料下,关系证据是否提高事实要点的检索覆盖率?
- RQ2:证据覆盖提高是否转化为更高的人工事实准确性和可追溯性?
- RQ3:不同方法在直接关系、来源追溯、集合查询、时间约束、指代和多关系聚合任务上的差异是什么?

## 2. 数据划分

- 使用至少 3 个项目。
- 每个项目不少于 20 个问题,总问题数不少于 60。
- 问题由未查看模型回答的人员依据已审核记录编写。
- 开发集用于调试检索参数,测试集在参数冻结后一次性运行。
- 同一事实的改写问题不得跨开发集和测试集。

## 3. 问题类型

- 资料事实型;
- 单跳实验对象关系型;
- 来源追溯型;
- 全量集合与计数型;
- 时间与实体约束型;
- 跨关系聚合型;
- 无答案/应拒答型。

每类在测试集中不少于 8 题。含“这些、上述、前三项”等指代的问题必须明确设置为多轮协议,否则改写为自包含问题。

## 4. 对照方法

所有方法使用同一生成模型、温度、最大输出和运行次数。

1. 纯 LLM,不提供项目证据。
2. 关键词/BM25 检索加生成。
3. 当前向量与词项混合 RAG。
4. 直接结构化查询,对可表达为数据库/图查询的问题返回确定性结果。
5. 当前一跳图谱增强 RAG。
6. 改进图谱检索:查询分解、关系类型配额、结构化过滤和连接聚合。

若无法实现第 6 项,必须从论文贡献中删除相应方法改进主张。

## 5. 预先冻结内容

运行前冻结并计算 SHA-256:

- 项目语料快照;
- 问题清单与类别;
- 每题答案要点和可接受同义表达;
- 无答案题的拒答标准;
- 主指标和次指标;
- 检索参数与提示版本;
- 统计检验与排除规则;
- 盲评表模板和随机种子。

冻结后不得根据模型回答修改规则。发现规则错误时,整批实验作废并建立新批次。

## 6. 指标

主指标:

- 人工事实准确率;
- 人工可追溯率;
- 答案要点证据覆盖率。

次指标:

- 规则化任务完成率;
- 完整列举准确率;
- 拒答准确率;
- 平均与 P95 时延;
- Prompt、Completion 和总 Token;
- 单题成本。

两名评价者独立评分时报告一致率和 Cohen's kappa。方法比较报告配对置信区间;统计检验只作为效应量和原始结果的补充。

## 7. 重复与随机化

- 每个“问题-方法”组合至少独立生成 3 次。
- 运行顺序随机化,避免时间顺序与服务波动系统性绑定。
- 盲评表隐藏方法、日志编号和运行顺序。
- 解盲键由评价完成后再合并。

## 8. 失败归因

每个未完成案例必须归入至少一类:

- 语料中无答案;
- 检索未覆盖必要事实;
- top-k 或上下文长度截断;
- 查询解析错误;
- 结构化过滤错误;
- 连接/聚合能力缺失;
- 证据已完整但生成遗漏;
- 生成引入无证据事实;
- 评价规则不充分。

## 9. 完成标准

只有同时满足以下条件,结果才能写入论文为确认性实验:

- 预注册文件与哈希早于任何正式回答;
- 所有基线按同一协议完成;
- 独立盲评签核完成;
- 原始日志、证据、规则和分析脚本可复查;
- 测试集未用于参数调优;
- 未完成和异常案例未被选择性删除。
