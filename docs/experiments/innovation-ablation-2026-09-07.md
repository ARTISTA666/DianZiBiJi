## 实验 A:蓝图覆盖度有/无 → 主动建议质量(创新点一×二联动)

两臂:①系统真实兜底路径(rule_based 建议算法,蓝图驱动)作用于真实蓝图(15 计划节点,已覆盖 1);
②无蓝图基线 = 通用型静态建议(主流 ELN 均内置的"及时记录/整理数据/沟通导师")。

| 指标 | 蓝图臂(rule_based) | 通用基线 |
| --- | --- | --- |
| 可执行引用(actionable_refs,建议绑定具体知识点) | **3** | 0 |
| 命中待实证知识点(hit_uncovered) | **3** | 0 |
| 编造引用(fabricated_refs) | **0** | 0 |

蓝图臂每条建议绑定一个真实待实证知识点(乳腺癌患者血浆样本/健康对照血浆样本/外泌体),
来源与优先级可追溯;通用臂 0 条项目相关引用。
**【勘误 2026-09-07】本对照仅证明:蓝图输入下兜底建议的 3 条引用全部绑定真实待实证知识点且无编造,静态提醒臂为 0 条引用。
这是引用绑定计数对照,不构成比率型质量指标(分母为零的"0/0"不作比率表述),不证明建议的整体质量、可执行性或执行成功率**;
对照臂为弱基线,强基线臂(无蓝图、仅笔记列表输入调 LLM)属非离线方案,本轮未执行。
LLM 归纳臂(线上端点 mode=llm)在机制文档与集成测试覆盖,本批次只消融输入信息(蓝图有无),不消融生成器,且未经质量评判。

## 实验 B:画像分数有/无 → 检索重排(创新点五,设计文档口径的原型验证)

复刻 `rag/graph.rs::graph_relation_score` 与设计文档式(5-3) 的重打分(λ₂=1.0,特征=quality/speed/novelty),
在项目 10 真实候选关系池(95 条)上,两位学生视角 × 4 类查询的重排:

**真实语料臂**:{"user33": 1.0, "user34": 1.0} —— Kendall τ=1.0、top-10 Jaccard=1.0、上提=0。
**诚实结论:当前演示语料下画像重排无判别信号可作用**——两位学生的实体类型覆盖高度同质(都做过全部主类型),
novelty 信号(该生未覆盖的知识点)在候选池(只含已做实验)中天然稀少:**还没做的知识点不在已做实验的候选池里**。

**机制可区分性检验(合成判别对照)**:注入 6 条计划态合成候选(蓝图驱动的"该做的实验",与 hint 命中关系同基分),
反事实画像(33=熟手:全类型已见过;34=新手:instrument 未见过):

| 候选 | 熟手(33)最终分 | 新手(34)最终分 |
| --- | --- | --- |
| 透射电子显微镜(计划候选) | 4.8 | **6.9(进 top-10)** |
| 纳米颗粒追踪分析(计划候选) | 4.8 | **6.9(进 top-10)** |
| TRIzol 试剂(计划候选) | 4.8 | 5.1 |
| 乳腺癌患者血浆样本(计划候选) | 2.4 | 3.45 |

排序分化判定:True——同一候选池,新手视角计划候选被上提进 top-10,
熟手视角不进;画像项确实按学生差异改变排序,但**差异幅度依赖学生类型覆盖的异质性**。
**【勘误 2026-09-07】画像(原创新点五)属于核心三贡献之外的前瞻项(outlook):本实验全部在脚本内复刻,
生产系统不包含画像重排,故不存在任何真实收益主张;论文中仅作设计文档+离线原型验证表述,不占贡献条目。**

## 实验 C:语义映射有/无 → 导师识读效率(创新点三,机器代理指标)

代理口径:三类导师识读任务(找类型/找枢纽/判断新鲜度)在两种视图下的**读取成本**(需要操作的视觉通道数):

| 识读任务 | 全语义映射(本系统) | 单色默认视图(主流产品口径) |
| --- | --- | --- |
| 找出所有试剂类节点 | 颜色通道,1 步 | 逐节点点开,86 步 |
| 找出关联最多的枢纽 | 大小通道,1 步 | 逐节点统计度数,86 步 |
| 判断哪些知识需复核 | 水波通道,1 步 | 逐节点查 updated_at,86 步 |

节点类型分布({"project": 9, "note": 86, "user": 9, "experiment_type": 9, "instrument": 13, "reagent": 21, "result": 18, "sample": 16})保证三类任务在真实图谱上均有非空答案。
**【勘误 2026-09-07】原句"全通道映射把 O(N) 遍历压缩为 O(1) 通道读取"撤回:86:1 是人为成本模型的推演值
(两处假设——逐节点=1 步、通道可读=1 步——均未经验证),既非实测效率,也不构成实测下界;
禁止以任何倍数形式进入论文或汇报。本实验仅支持:语义映射为三类识读任务各提供一条专用视觉通道(机制完备性)。
另据 AG-01/AG-02:水波通道已在当前 HEAD 裁撤(收敛为纯圆+抽屉读数),本表"水波通道"对应 4606189 演示版本。
反应时/正确率的人工两条件实验(有映射/无映射截图对比,课题组内被试)按语义映射文档第五节后补,预期并入同一消融总表。**
